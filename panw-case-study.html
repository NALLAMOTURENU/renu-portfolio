What I Built

AI-Powered Root Cause Analysis (RCA)

Built an automated engine that instantly aggregates and analyzes data across disparate backend systems (including RDS, AWS CloudWatch, EKS, and GCP Pub/Sub) to pinpoint exact points of failure in provisioning pipelines.

Knowledge Ingestion System

Engineered a scraper that continuously ingests historical troubleshooting threads from engineering messaging channels to actively capture siloed tribal knowledge and guide future engineers.

Multi-Interface Delivery

Decoupled RCA generation from the frontend, delivering diagnostics through an interactive React Web UI, a real-time ChatOps integration, and asynchronous machine-to-machine messaging via GCP Pub/Sub.

Automated QA Diagnostics

Architected a bi-directional Pub/Sub integration that empowered internal ephemeral QA environments to automatically debug their own infrastructure failures without human intervention.

Single-Click Orchestration

Automated the end-to-end infrastructure onboarding lifecycle by chaining individual operations into a unified workflow, reducing provisioning time from several hours down to approximately 30 minutes.

Unified React Platform

Developed a centralized frontend hub featuring a dashboard that maintains a permanent historical record of provisioned infrastructure and automatically stores RCAs for failed runs, optimizing LLM API token costs.

Context-Aware AI Assistant

Integrated a conversational AI advisor connected to internal knowledge bases that accurately answers provisioning queries and dynamically routes users to the precise internal Point of Contact.

System Reliability Engineering

Hardened the architecture by upgrading the PostgreSQL database, engineering a dedicated queuing system for automated notifications, and implementing LLM safeguards such as a 5-minute timeout and a 40-slot concurrency limit.
